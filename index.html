Privacy Policy: Bap Dadar Rasta

Effective date: November 2, 2026 · Developer: abc soft · Contact: infi@abcsoft.bd

This policy explains what information the Android game Bap Dadar Rasta (package com.dhakadrive.destruction, “the game”) handles.

Summary: the game does not collect, transmit, sell or share any personal data. It works fully offline and does not request the internet permission, so it cannot send data from your device.

What the game stores on your device

The game keeps one save file in its private app storage on your device. It contains:

  • in-game money, statistics (for example distance driven and number of crashes), mission progress and stars;
  • your local leaderboard: your top 10 damage scores, the date and time of each run, and combo records;
  • your settings (graphics quality, frame limit, volumes, control layout, vibration and tilt steering).

This information never leaves your device through the game. Uninstalling the game deletes it. “Reset scores” on the Leaderboard screen deletes the leaderboard.

Android backup

The game opts out of Android’s app-data backup, so the save file is not copied to cloud backups. Progress stays on the device where it was earned.

Permissions

PermissionWhy
VibrateShort vibrations on crashes and bumps. You can turn this off in the game settings.

The game does not request internet, location, camera, microphone, contacts, storage or any other permission. If you turn on tilt steering, the game reads the phone’s motion sensor only to steer while you play. These readings are not stored or sent anywhere.

Voices and audio

Voice lines in the game are pre-recorded audio files bundled inside the app. The game does not record, listen to or process your voice or any other audio from your device.

The “Privacy Policy” button

The game’s Settings screen has a “Privacy Policy” button. Tapping it asks your device to open this page in your web browser, which is a separate app. The game itself does not connect to the internet and does not send any data when you tap it. Your browser loads the page, and the browser’s and the web host’s own privacy practices apply to that visit. This page is hosted on GitHub Pages. If you are offline, the page will not load until you are connected; the game keeps working normally.

Advertising, analytics and third-party services

The game contains no advertising, no analytics, no crash-reporting service, no social login and no third-party SDKs that collect data. It is built with the open-source Godot Engine, which does not send data from the game.

Children

The game does not knowingly collect personal information from anyone, including children, because it does not collect personal information at all.

Changes

If a future version changes how data is handled (for example by adding online features), this policy will be updated before that version is released, and the effective date above will change.
